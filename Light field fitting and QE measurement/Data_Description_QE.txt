The file QE.npz is generated by QE_measurement.py, which holds a single 3D array named Coefficients_4x with shape (1024, 1280, 3). 
The three dimensions of the coefficient array map to the physical parameters as follows: 
Index 0 (coefficient a) denotes the dark current; 
Index 1 (coefficient b) represents the linear photoelectric conversion coefficient; 
Index 2 (coefficient c) represents the nonlinear photoelectric conversion coefficient.
